# Contributing to Meshtastic Configuration Manager

Thank you for your interest in improving this project.

This tool was created with a lot of personal work and AI assistance, and contributions of any size are very welcome.

## Ways to contribute

You can help by:

- reporting bugs
- suggesting improvements
- improving documentation
- testing on different hardware or Windows environments
- submitting code changes

## Before you start

Please:

- read the README first
- check existing Issues before opening a new one
- use GitHub Discussions for general questions or ideas
- use GitHub Issues for bugs, regressions, and feature requests

## Reporting bugs

When opening a bug report, please include as much useful information as possible:

- Windows version
- Python version, if relevant
- device or board model
- what you were trying to do
- what happened instead
- error message or traceback
- steps to reproduce the issue
- screenshots, if helpful

## Suggesting improvements

Feature suggestions are welcome.

Please describe:

- the problem you want to solve
- your proposed improvement
- why it would be useful
- whether it affects one node or fleet workflows

## Development workflow

If you want to contribute code:

1. Fork the repository.
2. Create a new branch for your change.
3. Make your edits in small, clear commits.
4. Test your changes before submitting.
5. Open a Pull Request with a clear description.

Example:

```bash
git checkout -b improve-json-export
```

## Pull request guidelines

Please try to keep pull requests:

- focused on one topic
- easy to review
- clearly described

In your pull request, explain:

- what changed
- why it changed
- how it was tested
- whether there are known limits or side effects

## Code style

There is no strict formal style guide yet, but please aim for:

- readable Python code
- explicit variable names
- small, understandable changes
- comments only where they add real value
- preserving existing behavior unless the change is intentional

## Documentation

Documentation improvements are extremely valuable.

You can contribute by improving:

- the README
- the wiki
- installation instructions
- examples
- English or French wording

## Be respectful

Please keep discussions and contributions polite and constructive.

Different experience levels are welcome.

## Questions

If you are not sure where to start, open a Discussion or look for Issues that are suitable for a first contribution.

Thank you for helping this project grow.
